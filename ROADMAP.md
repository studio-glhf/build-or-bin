# Build or Bin Roadmap

## Goal
Reach 10 organic GitHub stars by making the repo and demo genuinely useful, polished, and easy to discover.

## Current thesis
A local-first founder idea filter can win lightweight organic attention if it is:
- fast to try
- visually sharp
- opinionated enough to feel helpful
- useful without signup or API keys
- well documented with a live demo

## Current shipped state
- static GitHub Pages app
- local-first browser storage
- six-factor scoring
- red-flag kill conditions
- exportable summary
- saved idea snapshots

## Next likely iterations
1. Better landing/demo storytelling above the tool
2. Side-by-side comparison mode for saved ideas
3. Sharper scoring rationale and suggestions by verdict
4. Better social preview / demo media for repo discovery
5. Portfolio mode for ranking multiple ideas

## Pivot triggers
Consider pivoting if:
- usage quality feels weak after several strong polish passes
- the repo remains too generic to earn attention
- a more specific wedge emerges from founder/product workflows
